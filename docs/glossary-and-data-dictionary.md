# 业务术语与数据字典

## 术语

| 术语 | 系统定义 | 备注 |
|---|---|---|
| 消防设施 | 学校纳入本系统管理的消防栓、灭火器及其他消防器材 | 每件设施有唯一编号 |
| 巡检 | 保安按照计划到现场对设施进行检查并提交记录 | 必须绑定二维码、定位、服务器时间和实时照片 |
| 保养 | ��周期对设施进行清洁、维护、压力检查或专业保养 | 可由校内人员或专业单位执行 |
| 技术更新年限 | 根据设备类型、生产日期、投用日期及适用标准计算的提醒依据 | 由管理员配置，不在代码中写死 |
| 异常 | 检查项不符合要求或设施需要维修、检测、更换 | 异常必须说明并形成整改任务 |
| 整改 | 对异常设施进行维修、保养、更换或复核的处理过程 | 完成后保留凭证 |
| 正式记录 | 已通过关键校验并提交成功的业务记录 | 普通保安不可修改或删除 |
| 演示记录 | 培训模式产生的练习数据 | 不进入正式统计和整改流程 |

## 设施字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| facility_no | 字符串 | 是 | 校内唯一设施编号 |
| facility_type | 枚举 | 是 | FIRE_HYDRANT、EXTINGUISHER、OTHER |
| name | 字符串 | 是 | 设施名称 |
| campus/building/floor/area | 字符串 | 是 | 校区、楼栋、楼层、区域 |
| detail_location | 字符串 | 是 | 文字位置描述 |
| latitude/longitude | 小数 | 否 | 现场定位坐标 |
| qr_token | 字符串 | 是 | 二维码安全令牌，唯一且可作废 |
| brand/model/specification | 字符串 | 否 | 品牌、型号、规格 |
| manufacture_date | 日期 | 否 | 生产日期 |
| commissioned_date | 日期 | 否 | 投入使用日期 |
| update_rule_id | 整数 | 否 | 技术更新规则 |
| last_maintenance_at | 日期时间 | 否 | 最近维护时间 |
| next_maintenance_at | 日期时间 | 否 | 下次维护时间 |
| lifecycle_status | 枚举 | 是 | IN_USE、MAINTENANCE、TO_REPLACE、RETIRED、TRANSFERRED |

## 账号角色

| 角色 | 主要能力 | 禁止事项 |
|---|---|---|
| ADMIN | 看板、用户、设施、计划、整改、审计和报表 | 无特殊限制，但关键变更必须留痕 |
| GUARD | 查看任务、现场巡检、提交异常 | 不能修改设施档案，不能修改/删除正式巡检 |
| COLLECTOR | 新增和维护设施档案、二维码和初始照片 | 不能修改正式巡检结果 |
| VISITOR | 查看允许公开的记录和统计 | 不能新增、修改、删除或提交 |

## 更新年限规则

规则至少包含设施类型、适用范围、计算基准、年限、提前提醒天数、生效日期、依据说明和版本号。规则变更不追溯修改已生成的历史提醒；管理员可对单件设施进行人工覆盖，但必须填写原因并写入审计日志。系统提醒仅作为管理依据，不替代消防专业检测或法规判断。
