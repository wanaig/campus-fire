# 角色权限矩阵

| 功能 | 管理员 | 保安 | 数据采集员 | 访客 |
|---|---:|---:|---:|---:|
| 查看公开设施和统计 | 是 | 是 | 是 | 是 |
| 查看全部内部数据 | 是 | 按任务范围 | 按授权范围 | 否 |
| 用户和角色管理 | 是 | 否 | 否 | 否 |
| 新增设施档案 | 是 | 否 | 是 | 否 |
| 修改设施档案 | 是 | 否 | 是（授权范围） | 否 |
| 拍摄设施初始照片 | 是 | 否 | 是 | 否 |
| 生成/作废二维码 | 是 | 否 | 是（授权范围） | 否 |
| 制定巡检计划 | 是 | 否 | 否 | 否 |
| 执行现场巡检 | 是（可代办并留痕） | 是 | 否 | 否 |
| 上传巡检留痕照片 | 否 | 是 | 否 | 否 |
| 查看设施/巡检照片 | 是 | 是 | 是 | 是（只读） |
| 提交正式巡检记录 | 是（需审计） | 是 | 否 | 否 |
| 修改/删除正式巡检记录 | 作废或更正审批 | 否 | 否 | 否 |
| 创建和分派整改任务 | 是 | 否 | 否 | 否 |
| 更新整改进度 | 是 | 可提交处理材料 | 可补充设施资料 | 否 |
| 查看审计日志 | 是 | 否 | 否 | 否 |
| 导出报表 | 是 | 否 | 按授权范围 | 否 |

> 未登录用户默认按访客权限处理。无障碍模式只改变显示和交互方式，不改变上述权限。
