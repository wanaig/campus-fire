# 第一版范围说明

## 目标

第一版用于一所学校、一个校区的小规模试点，验证从设施建档到巡检整改的完整闭环。

## MVP 必须包含

1. 管理员、保安、数据采集员和访客四类权限。
2. 消防设施档案、位置、日期、状态和照片管理。
3. 每件设施的唯一二维码生成、补打和作废。
4. 巡检计划、任务分配和逾期识别。
5. 保安现场扫码、定位、实时拍照和服务器时间留痕。
6. 动态检查项、异常说明和正式记录提交。
7. 异常自动生成整改单并完成处理闭环。
8. 设施、巡检、异常、维护和更新年限的基础看板。
9. 大字体、大按钮、高对比度、语音提示和简易巡检模式。
10. 用户操作、记录作废和更正的审计日志。

## 第二阶段

- 批量 Excel 导入和复杂报表模板。
- NFC 或蓝牙近场校验。
- 重复照片和异常移动速度等高级风险识别。
- 企业微信、短信或学校统一身份认证。
- 多校区和跨学校多租户能力。

## 暂不开发

- AI 自动判断消防设施是否合格。
- 物联网传感器实时数据采集。
- 替代消防检测机构出具专业结论。
- 自动确定所有设施的法定报废年限。

## MVP 成功标准

- 50 至 200 件真实设施可以完成建档和二维码张贴。
- 保安能独立完成扫码、检查、拍照和提交。
- 非现场、相册照片或缺少关键证据的巡检不能形成正式记录。
- 异常记录能够被分派、处理、复核和关闭。
- 管理员能够查看数据并导出基本台账。
